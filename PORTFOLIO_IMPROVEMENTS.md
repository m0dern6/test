# Modern Flutter Portfolio

A beautiful, responsive, and interactive portfolio website built with Flutter Web.

## ✨ New Features & Improvements

### 🎨 Modern Design
- **Glassmorphism effects** with translucent cards and backdrop filters
- **Gradient backgrounds** and color schemes
- **Smooth animations** and micro-interactions
- **Modern typography** using Google Fonts

### 📱 Responsive Design
- **Mobile-first approach** with dedicated mobile layouts
- **Tablet support** with optimized medium screen layouts
- **Desktop experience** with advanced features and layouts
- **Adaptive navigation** - drawer for mobile, top nav for desktop

### 🚀 Interactive Elements
- **Hover effects** on cards and buttons
- **Animated progress bars** for skills
- **Floating particles** background animation
- **Smooth scrolling** between sections
- **Page transitions** with fade and slide effects

### 🧩 New Components
- **GlassCard** - Modern glass-like containers
- **CustomButton** - Interactive buttons with animations
- **HoverCard** - Cards with hover transformations
- **Responsive utilities** for different screen sizes

### 📋 Enhanced Sections

#### 🏠 Home Section
- Dynamic greeting with wave animation
- Floating skill badges around profile image
- Call-to-action buttons
- Social media links

#### 👨‍💻 About Me Section
- Statistics cards with animated counters
- Skill bars with progress animations
- Experience and education timeline
- Professional summary cards

#### 🛠️ Tech Stack Section
- Interactive technology cards
- Skill level indicators
- Modal dialogs with technology details
- Grid layout responsive to screen size

#### 💼 Projects Section
- Featured project showcase
- Project carousel for mobile
- Interactive project list
- Technology tags and live demo links

#### 📞 Contact Section
- Contact form with validation
- Interactive contact methods
- Social media integration
- Modern form design with animations

### 🎯 Technical Improvements
- **Better state management** with proper animations
- **Performance optimized** with efficient widgets
- **Clean architecture** with organized file structure
- **Modern themes** supporting both light and dark modes

## 🚀 Getting Started

1. Make sure you have Flutter installed
2. Clone the repository
3. Run `flutter pub get` to install dependencies
4. Run `flutter run -d chrome` to start the web app

## 📁 Project Structure

```
lib/
├── constants/         # App constants and data
├── pages/             # Screen components
├── theme/             # Theme configuration
├── utils/             # Utility classes
├── widgets/           # Reusable UI components
└── main.dart          # App entry point
```

## 🎨 Customization

You can easily customize:
- Colors in `utils/app_colors.dart`
- Personal information in `constants/` files
- Animations in `utils/animations.dart`
- Themes in `theme/` directory

## 📱 Responsive Breakpoints

- **Mobile**: < 650px
- **Tablet**: 650px - 1100px  
- **Desktop**: > 1100px

The portfolio now provides an exceptional user experience across all devices with modern design patterns and smooth interactions!
